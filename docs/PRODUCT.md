# LizPink 个人终端

文中的文件路径均以项目根目录为基准。

## 目标与访客

这是 LizPink 的个人网站，供访客了解经历、项目、生活。role配置值为“学生”，首页由UI添加“职业：”标签并使用与关注行一致的普通次要文字色显示“职业：学生”，兴趣为 Computer Graphics、Computer Engineering、Games、Artificial Intelligence；自我介绍、身份与兴趣集中在首页，经历不再重复这些资料。

**用户图示与最新明确修订是最高优先的产品约束。** 网站铺满视口并融入统一背景，不设置外框、机壳套窗或居中限宽容器。保留原 `lp_` 标志与 LizPink 并排，桌面内容目录可展开、折叠及调宽，手机使用抽屉。

Markdown内容源码分离与本页目录已并入 `main`，作为当前正式维护流程。作者内容位于 `content/`，UI源码位于 `site/`，`dist/` 由构建生成。线上版本以对应 GitHub Actions 部署结果为准。

## 当前结构与交互

- 内容目录顶部按首页、生活01、经历02、项目03逐行排列，下方每条显示分区、日期和标题；home/help显示全部内容的去重并集。栏目归属来自独立Markdown的sections，构建器生成各栏目引用列表；左侧全量目录和分区最近列表统一优先updatedAt、无则publishedAt降序排列，无日期置后，同日保持稳定顺序。个人介绍在首页，旧命令不兼容。
- 7个公开命令依次为 `home / 0`、`life / 1`、`resume / 2`、`project / 3`、`open`、`close`、`help`。`site/assets/js/commands.js` 是单一命令表，派生解析路由、Tab候选和帮助。视图只保留home、life、resume、project、help；仅保留现行命令、0–3及当前中文简写。clear已移除，不执行也不出现在补全、帮助或建议中；无效hash显示首页，未识别命令提示帮助。
- 首页显示greeting问候、role职业、interests关注内容、about个人介绍与命令区；顶层description及对应HTML description meta均删除。role只填“学生”，UI添加“职业：”，使用与关注行一致的普通次要文字色，不使用黄色强调。“关注”行按主区实际剩余宽度排布，不受72ch提前限宽，空间不足才自然换行；about正文继续按可读行宽限制，窄屏不溢出。首页资料仅在home显示，进入其他栏目立即隐藏并释放占位；首次打开首页自动聚焦输入，空输入时在光标旁提示“输入 help 查询命令”，开始输入后隐藏提示。
- 页面、工具栏、框架和主区采用同一屏幕底色，外框、主区内框与套窗内缩均为零，仅保留工具栏和侧栏内部细分隔线。独立页头、页脚与版权条均不占页面空间。
- 桌面目录默认展开、宽200px，占独立列；工具栏入口始终可见，目录内部可收起。拖动separator可调180–420px，同时给主区至少320px；左右键每次16px、Home/End最小/最大、双击恢复200px、Escape取消拖动。取消图钉、悬停peek与移出延迟收起。
- 桌面展开选择和偏好宽度只存本次会话，跨导航及手机往返保留，不写localStorage，刷新恢复默认。760px及以下每次进入手机模式先关闭抽屉；工具栏打开，焦点循环包含关闭、栏目与条目。关闭、Escape或遮罩后返回工具栏焦点，选择后聚焦正文。
- 唯一原生输入采用自动吸附：原输入位置不可见时停靠底部，原位置可见时回到正文之后。首页首次加载自动进入命令模式，并在首页资料下方保留输入原位；之后可按 `/`、点击输入或闲置提示重新激活。有命令输出时，编辑期间固定在底部，执行后可连续输入；Enter 执行，手机使用发送键。镜像块光标保留原生编辑与中文输入，不添加独立执行箭头。
- 每次有效栏目命令替换旧输出，显示当前回显、页面和唯一输入区，并从顶部开始；↑↓命令历史继续保留。life/resume/project默认显示h2栏目标题、常驻description与最多10条最近内容，仅含日期和标题，不足10条按实际显示。经历还常驻简历行，有PDF时显示入口，无PDF时显示“PDF待添加”。展开时只隐藏最近列表，栏目标题、说明和简历行不隐藏、不重复；关闭后恢复概览。全文首次展开才创建正文和媒体，收起后保留，关闭或后续导航暂停旧视频。
- 新命令或点击导航后的摘要按完整条目渐显（最长280ms），帮助按命令整行渐显（最长550ms）；输入始终可用。新命令或主动阅读立即完成旧展示。初始/历史导航、减少动态效果、页面隐藏及结果超出可见高度时直接展示；长文与媒体仍按需展开。
- 新页面先取消待执行的跟随帧，替换旧输出并将main.scrollTop归零。编辑、Tab补全、↑↓历史回调与 `/` 聚焦保持正文位置；较长帮助页同样从顶部显示，未知命令保留当前页面。
- 命令模式中 `Esc` 有补全时先关闭候选，再按一次返回正文并保留草稿；“返回阅读”按钮直接退出，手机也可使用。退出后恢复自动吸附，保留Shift+Tab离开路径。输入元素只在初始化时移动一次，滚动和切换位置不移动、不复制输入，不再使用独立“返回输入”按钮。
- 当前分区若有详情，`open` 展开全栏正文并定位，命令模式中仍保留输入焦点；`close` 收起并回到概览与输入，常驻标题、说明和简历行不变。`help` 正文依次显示“浏览路线”“操作”两组命令及“侧栏快捷键”分组，底部保留原有六条编辑快捷键；栏目描述为首页、生活、经历、项目，操作描述为展开、收起、帮助；详情按钮同步使用展开/收起。命令按钮最小44px高，数字选项独立对齐，使用CSS Grid的8ch命令列，不用制表符。
- 点击侧栏或帮助中的浏览命令会替换页面，从正文顶部开始阅读，焦点留在正文；键盘提交栏目命令同样替换页面并置顶，继续保留输入焦点；同栏目重输也刷新。数字或中文简写统一回显英文命令，例如2显示为resume；↑↓保留实际输入历史。home恢复首页资料。各分区使用同一概览结构和日期规则，不再显示媒体数量；个人介绍只在首页，真实resume.sections仅在经历全文，PDF入口只在常驻简历行。
- 点击目录条目或最近列表标题进入如 `#project/geometry` 的单条正文，支持深链与浏览器前后导航。单条直接显示所选全文，仅创建该条媒体，不含折叠详情，open/close提示没有可展开详情。7个命令与栏目summary/details仍保留。
- 单条标题用h2，栏目详情条目仍用h3、经历条目用h4；Markdown正文的h2/h3在渲染时调整到文章内部层级。文字最大72ch且左对齐；媒体自身最大960px，在剩余主区居中，按自然比例显示，小媒体不放大。手机主区左右内边距20px，480px及以下事实标签和值上下排列。
- 正文图片普通点击在同页暗背景中居中预览；`Esc`、右上角×或图片外空白关闭，返回原图与原滚动位置。`Ctrl`/`Meta`/`Shift`修饰点击保留原图外链行为；不支持同页预览时沿用原图链接。预览保持自然比例，不增加轮播或缩放；视频继续使用原生控件，作者不必修改Markdown。
- 本页目录从当前Markdown正文的h2/h3自动生成，至少两个有效文章章节标题时显示，不收录分区最近10篇标题。`.frame-main`可用宽度达到1000px时默认使用右侧180px目录列；更窄时默认使用正文顶部的折叠details。手动选择优先：宽屏隐藏时释放右列，窄屏展开/折叠内容时仍保留summary入口；选择在本次会话跨文章与宽窄切换保留，刷新恢复响应式默认。点击章节暂停跟随，只滚动main并聚焦标题，不改写当前内容hash；目录高度为吸附输入区留出空间。
- `Ctrl+Alt+A` 切换左侧内容目录，`Ctrl+Alt+B` 切换当前本页目录；帮助正文在“操作”后新增“侧栏快捷键”，分别列出“Ctrl+Alt+A 显示/隐藏左侧目录”和“Ctrl+Alt+B 显示/隐藏右侧目录”，不再放入底部紧凑快捷键区，正文与工具栏仍称“本页目录”。工具栏本页目录按钮提供按键提示，手机仅显示图标；没有有效本页目录时隐藏入口，B组合键不处理。两组合键在命令输入模式可用并保留草稿，切换不主动改写hash或滚动位置；IME组合输入、AltGr和其他编辑区不触发。
- Tab 在输入中补全，非 Shift 的 Tab 始终保持输入焦点：唯一匹配补全、多匹配循环列表候选、空输入也可使用、无匹配不跳焦。成功补全只更新候选与输入选区，不显示底部状态文案；无匹配及未知命令继续显示错误说明。Shift+Tab 可离开，↑↓ 回调历史。未激活且空输入时显示静态空心光标和“按下 / 输入命令 · 输入 help 查询命令”按钮；窄屏分两行。有草稿时保留草稿与静态空心光标。仅input聚焦、页面有焦点且可见时显示实心闪烁光标；激活空输入时旁边显示“输入 help 查询命令”，开始输入即隐藏。右侧在命令模式显示“Esc 返回阅读”。组合输入、其他编辑区、文字选择、媒体与目录上下文不触发快捷唤起。错字建议比较完整拼写，例如 `proejct` 提示 `project`。
- 宽屏工具栏“就绪 / 输入中”同步真实输入，1000px以下隐藏。工具栏目录入口、内部收起按钮和separator提供无障碍名称与状态。命令回显100ms、输出180ms、详情160ms淡入，输入态颜色及详情箭头短过渡；定位按帧合并，只写变化样式。减少动态效果及隐藏页面暂停规则保持。
- 默认琥珀，另有荧绿；工具栏右侧为一个两档开关，checked 表示荧绿。760px 以下隐藏路径和当前主题文字以保持单排，开关语义仍完整。URL与偏好优先级保留，只有手动切换开关保存；配色仅通过右上角开关切换，不提供theme命令。
- 命令输入、回显、路径与快捷键使用本地 IBM Plex Mono Regular 400 / Medium 500；中文说明、摘要与详情沿用既有衬线字体。IBM字体来自官方仓库，随附 SIL OFL 1.1 许可。

## 唯一输入体验

自动吸附与命令模式已选定为唯一默认体验，由 `site/assets/js/command-input.js` 与 `site/assets/css/command-input.css` 提供。版本切换栏、对比页和其他输入分支已移除。旧链接中的 `input` 参数清除后进入同一最终版本，保留主题参数与栏目位置。

首次打开首页在完成初始化后调用focus({preventScroll:true})自动聚焦输入，不移动到页底；直接打开栏目时显示说明和最近10条概览；单篇内容深链直接显示全文并保持阅读状态。自动聚焦只在首页初始化时执行，不在窗口恢复焦点后反复抢焦点。只保存用户手动选择的主题，不持久保存命令模式或草稿。

## 内容边界与维护

内容与页面逻辑分开维护。`content/site.yml` 保存真实使用的品牌与首页资料、正式简历及每栏唯一的paths.description，不再维护重复的introduction；`content/entries/{key}/index.md` 每篇独立，图片、MP4、封面与字幕随篇保存。栏目归属由文章元信息 `sections` 决定，同一篇可跨分区共享；作者不维护 `paths.items`，该列表由构建器生成。简历公共文件放在 `content/files/`。

元信息使用标题、栏目和可选日期，不设置 `example` 或 `dateExample` 字段。原有六篇内容仍是排版演示，每篇正文第一段明确说明“本文为排版示例，日期为演示日期”；说明、alt与图注保留，不作为真实个人经历或成果。正文标题下始终显示“创建于 … · 更新于 …”，分别使用publishedAt（创建/首次发布日期）与updatedAt（真实更新日期），不新增createdAt；某项缺失显示“—”，只对有效日期生成time元素，不把创建日期复制成更新日期。列表与左栏仍只用单一有效日期，updatedAt优先、其次publishedAt，无日期置后并省略列表日期。真实记录填写真实日期，不补造；示例性质继续由正文说明。

Markdown中的本地媒体引用决定展示位置；只复制素材而未引用不会展示。MP4按扩展名转成播放器，同名 `.poster.*` 与 `.zh.vtt` 自动关联。原始HTML按文本显示。本页目录来自正文h2/h3，不另维护目录元信息。日常操作见[内容维护指南](CONTENT.md)。

网站公开地址为 [lizpink.github.io](https://lizpink.github.io/)。发布状态以对应 GitHub Actions 任务结果为准，历史版本通过Git提交查看。

## 源码、构建与发布

`site/` 是HTML、CSS、JavaScript及本地字体等UI源码；`content/` 是作者内容源。`dist/` 是 `npm run build` 生成的完整站点，已加入gitignore，不手改、不提交为内容源。

`scripts/build-content.mjs` 读取站点YAML与各篇Markdown，生成内容数据、标题索引和所引用资源；`scripts/build.mjs` 将UI源码复制到暂存区、生成内容、替换站点字段，全部成功后原子替换 `dist/`，避免发布未完成的构建。

`npm run dev` 默认在 [127.0.0.1:4182](http://127.0.0.1:4182/) 预览，监听 `content/` 与 `site/`，成功重建后自动刷新浏览器。`npm test` 先构建再运行全部 `tests/`；`npm run build` 可单独生成发布站点。

正式版本保存在 `LizPink/LizPink.github.io` 的 `main` 分支，Markdown内容与本页目录按当前流程统一维护。功能分支用于开发与预览，推送功能分支不更新线上网站。`.github/workflows/deploy-pages.yml` 仅在main运行：`npm ci` 安装锁定依赖，`npm test` 构建并检查，通过后部署 `dist/`。推送main后自动触发发布，结果以对应 GitHub Actions 任务为准。Sites与GitHub Pages独立部署。
