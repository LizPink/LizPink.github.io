# 网站功能说明

LizPink 个人终端是一个个人网站，用于介绍自己、整理经历、展示项目和记录生活。访客既可以点击目录浏览，也可以输入命令切换内容。

本文说明网站如何使用。新增文章、上传素材和发布网站的步骤见[内容维护指南](CONTENT.md)；布局尺寸、颜色和交互实现见[设计说明](DESIGN.md)。

## 页面布局

网站铺满浏览器窗口，使用统一背景。顶部工具栏显示 `lp_` 标志、LizPink、当前所在位置，以及目录和外观切换按钮。

桌面上，左侧是内容目录，中间是阅读区。文章有足够的章节标题时，阅读区右侧还会显示“本页目录”。命令输入区位于正文之后；阅读较长内容或输入命令时，它会停靠在底部。

正文和界面使用清晰的思源黑体，首页问候、栏目标题与站点名称保留衬线字体；命令、路径和快捷键使用等宽字体。正文黑体与等宽字体由网站本地提供，正文加粗使用字库自带的粗体字重。文章文字使用正文列的全部可用宽度，图片和视频在可用区域内居中，按原始比例显示，图片说明在图片下方居中。

## 各页面显示什么

| 页面 | 显示内容 |
| --- | --- |
| 首页 | 问候、职业、关注方向和个人介绍。 |
| 生活 | 栏目说明，以及最多 10 条最近内容。 |
| 经历 | 栏目说明、简历入口，以及最多 10 条最近内容。 |
| 项目 | 栏目说明，以及最多 10 条最近内容。 |
| 帮助 | 可用命令、侧栏快捷键和输入操作说明。 |

职业以“职业：学生”这样的形式显示，与“关注”使用相同的次要文字色。首页资料只在首页出现，切换栏目后，阅读区用于展示对应内容。

三个内容栏目使用相同的浏览方式：先看说明和最近内容，点击标题阅读一篇文章，也可以用 `open` 展开该栏全部内容，再用 `close` 收起。展开和收起时，栏目标题、说明和简历入口始终保留。

经历页面始终保留“简历”一行。配置 PDF 后显示打开入口；尚未配置时显示“PDF 待添加”。教育、实践和技能等简历条目在经历的展开内容中显示。

栏目尚无文章时显示“这个分区还没有内容。”，左侧列表显示“这个栏目还没有内容。”。首页资料和简历入口仍可使用。

## 内容如何排列和阅读

### 列表与日期

左侧目录列出当前栏目的全部文章，栏目首页只列最近 10 条。列表按日期从新到旧排列：优先使用更新日期，没有时使用创建日期；没有日期的文章排在最后，相同日期保持原有顺序。

每篇正文标题下显示两个日期：

- **创建于**：文章的创建或首次发布日期，来自 `publishedAt`。
- **更新于**：优先使用手填的 `updatedAt`；未填写时，由程序在生成网站时根据这篇文章后续的 Git 提交记录计算。

新文章只填写创建日期即可，首次创建时“更新于”与创建日期相同。以后提交该篇正文或素材的修改，再生成网站，更新日期会使用最近一次后续内容提交的北京时间日期。文章目录中的图片、视频和各层子文件夹都属于这篇内容。

已有文章尚未提交的本地修改，会继续使用最近已提交的更新日期；新文章尚未提交时，使用创建日期。重新构建网站，以及对网页代码或其他文章的修改，都不会刷新这篇文章的日期。

未手填更新日期，且 Git 历史不完整、没有记录或 Git 不可用时，更新日期回退到创建日期。创建日期未填时显示“—”，完全没有可用日期时两项均显示“—”。计算结果只用于生成网站，不改写文章文件，也不使用电脑上的文件修改时间。列表只显示一个用于排序的日期。

本地提交后，可运行 `npm run build` 并刷新浏览器，或重新启动预览，查看新的更新日期；提交本身不会刷新已经开启的预览。

### 打开文章与切换栏目

点击左侧条目或最近内容的标题，会直接打开整篇文章。每篇文章都有独立链接，例如 `#project/my-note`，可以分享，也支持浏览器的前进和后退。

切换栏目时，阅读区替换为新内容，并从顶部开始显示。再次输入当前栏目命令，也会返回该栏概览。输入数字或中文名称后，页面统一回显英文命令，例如输入 `2` 后显示 `resume`。

单篇阅读页直接展示全文，`open` 和 `close` 只用于栏目概览；在单篇页面使用它们时，会提示当前没有可展开的详情。

### 图片、视频和展示动画

点击正文图片，可在当前页面的暗背景中查看大图。按 `Esc`、右上角的 × 或图片外的空白处关闭，回到原来的阅读位置。按住 `Ctrl`、`Meta` 或 `Shift` 点击时，保留浏览器打开原图的方式。

视频使用浏览器自带的播放控件。收起内容或离开页面时，旧页面中的视频会暂停。栏目全文在首次展开时才创建对应正文和媒体，减少初次浏览时的加载量。

一篇文章可以包含多张图片和多个视频。素材可按 `photos/`、`videos/` 等子文件夹整理；每个视频按所在文件夹和名称匹配自己的可选封面、字幕，不同子文件夹可使用相同的视频文件名。

Markdown 可与常见 HTML 排版混写，HTML 图片、链接、标题、段落、列表和表格进入同一套内容解析；HTML 标题也参与本页目录，图片仍支持同页大图。图片可通过 HTML 的宽度或缩放设定显示尺寸。脚本、事件属性和不支持的标签不作为可执行内容输出，代码示例保持原样。

两种写法均兼容正斜杠、反斜杠和指向本篇素材的本机绝对路径，构建时统一转为发布路径并复制素材；跨机器构建可识别 `content/entries/当前文章名/` 路径后缀。原始文章不被改写，文章目录外的资源不读取。

命令执行后，列表按条目、帮助按命令行依次渐显。输入区始终可用；继续执行命令或开始阅读时，剩余内容会立即显示。启用系统的“减少动态效果”设置后，内容直接显示。

## 命令与快捷键

### 页面命令

在输入区输入命令，按 `Enter` 执行；帮助页中的命令也可以直接点击。

| 命令 | 数字或中文写法 | 作用 |
| --- | --- | --- |
| `home` | `0`、首页 | 返回首页。 |
| `life` | `1`、生活 | 打开生活。 |
| `resume` | `2`、经历、简历 | 打开经历。 |
| `project` | `3`、项目 | 打开项目。 |
| `open` | 展开 | 展开当前栏目的全部内容。 |
| `close` | 收起 | 返回当前栏目的概览。 |
| `help` | 帮助 | 查看命令和快捷键。 |

输入无法识别的命令时，网站会保留当前页面，并提示查看帮助；接近正确拼写时会给出建议。无法识别的栏目链接会返回首页；文章不存在时，显示对应栏目的概览。

### 输入和目录快捷键

| 按键 | 作用 |
| --- | --- |
| `/` | 开始输入命令。 |
| `Enter` | 执行当前命令；手机可使用键盘的发送键。 |
| `Tab` | 补全命令；有多个候选时继续按可依次选择。 |
| `↑`、`↓` | 找回之前输入的命令。 |
| `Esc` | 先关闭补全候选，再按一次返回阅读，保留草稿。 |
| `Shift+Tab` | 从命令输入区移到前一个可聚焦控件。 |
| `Ctrl+Alt+A` | 显示或隐藏左侧内容目录。 |
| `Ctrl+Alt+B` | 显示或隐藏当前文章的本页目录。 |

侧栏组合键也可在输入命令时使用，不会清空草稿。中文输入法正在组合文字、编辑其他输入框等情况下，网站会保留相应的编辑操作。

## 命令输入状态

首次打开首页会自动进入输入状态，可以直接键入命令；直接打开栏目或文章链接时，保持阅读状态。返回浏览器窗口后，不会反复把焦点抢回输入区。

| 状态 | 页面表现 |
| --- | --- |
| 未激活 | 显示静止的空心光标。空输入旁提示“按下 / 输入命令 · 输入 help 查询命令”。 |
| 正在输入 | 显示实心闪烁光标。空输入旁提示“输入 help 查询命令”，开始键入后隐藏提示。 |
| 页面失去焦点或不可见 | 停止光标闪烁。 |

启用“减少动态效果”时，激活光标也保持静止。命令输入区用柔和背景表示激活状态。

点击输入区或提示文字，可以重新开始输入。有命令输出时，编辑中的输入区固定在底部，方便连续执行命令；返回阅读后，它随正文位置自动停靠或回到正文之后。点击“返回阅读”也能直接退出输入状态并保留草稿。

## 两个目录如何使用

### 左侧内容目录

顶部依次是首页、生活、经历和项目，下方条目显示“分区 + 日期”和文章标题。首页与帮助页显示全部文章，同一篇跨栏目文章只列一次。

桌面默认展开目录。可用工具栏按钮、目录内的收起按钮或快捷键切换显示；拖动边界调整宽度，双击恢复默认宽度。边界也支持键盘左右键调宽、`Home` 和 `End` 调到两端，`Esc` 取消当前拖动。

目录宽度和展开状态在本次访问中保留，刷新后恢复默认。手机上，目录改为从左侧打开的抽屉；点击遮罩、关闭按钮或按 `Esc` 可关闭，选择内容后进入阅读。

### 本页目录

本页目录来自文章中的 `##`、`###` 或 HTML `h2`、`h3` 标题，至少有两个有效章节标题时出现。它只展示文章内部结构。

空间充足时，目录显示在正文右侧；空间较小时，放在正文顶部，默认收起。可通过工具栏按钮或 `Ctrl+Alt+B` 切换。没有可用目录时，按钮隐藏，快捷键不生效。

点击章节后，阅读区滚动到对应位置，文章链接保持不变。手动选择的显隐状态在本次访问中保留，刷新后按屏幕宽度恢复默认布局。

## 外观与手机使用

首次访问默认使用深色模式：深色背景、暖白文字和琥珀强调色，说明文字保持清楚可读。浅色模式使用暖白背景、深墨文字和墨蓝强调色。工具栏右侧始终只显示太阳和月亮图标按钮，分别切换浅色和深色模式；悬停提示和无障碍名称保留，选中项有边框与底色，网站会记住手动选择。

打开带有有效外观参数的链接时，优先使用链接指定的模式；否则使用已保存的选择，再回退到深色。旧的琥珀和荧绿模式链接会归入深色模式。两种模式下，图片大图预览都使用暗背景。

手机上收起较次要的工具栏文字，外观按钮与桌面一样只显示图标，并保留足够大的点击区域。正文、媒体、输入区和补全列表会随可用空间调整。按钮与目录文字可点击但不可选中，正文和输入内容可以选择、复制；键盘操作仍有清楚的焦点提示。

## 内容维护与发布

文章和网站功能分开维护。日常写作主要操作 `content/`，页面布局与交互由 `site/` 管理。

| 要修改的内容 | 位置 |
| --- | --- |
| 首页资料、栏目说明和简历配置 | `content/site.yml` |
| 一篇文章的标题、栏目、日期和正文 | `content/entries/文章文件夹/index.md` |
| 这篇文章的图片、视频、封面和字幕 | 放在该篇文章目录内，可用 `photos/`、`videos/` 等子文件夹整理。 |
| PDF 简历等公共文件 | `content/files/` |
| 页面布局和交互 | `site/` |
| 构建和检查脚本 | `scripts/`、`tests/` |

同一篇文章可归入多个栏目，文章列表和本页目录自动生成。新增内容的模板、媒体写法与预览步骤见[内容维护指南](CONTENT.md)。源码职责和界面检查项目见[设计说明](DESIGN.md#检查清单)。

网站公开地址为 [lizpink.github.io](https://lizpink.github.io/)。推送 `main` 后，GitHub Actions 自动构建、检查并发布；开发分支用于预览，推送后不会更新线上网站。`dist/` 是自动生成的发布目录，维护时修改源文件即可。发布是否完成，可在对应的 GitHub Actions 任务中查看。
