# LizPink 个人终端

文中的文件路径均以项目根目录为基准。

## 目标与访客

这是 LizPink 的个人网站，供访客了解经历与能力、研究与探索、生活与记录。身份已确认是学生（Student），兴趣为 Computer Graphics、Computer Engineering、Games、Artificial Intelligence；自我介绍、身份与兴趣集中在经历与能力，不在首页重复展示。

**用户图示与最新明确修订是最高优先的产品约束。** 网站铺满视口并融入统一背景，不设置外框、机壳套窗或居中限宽容器。保留原 `lp_` 标志与 LizPink 并排、默认收起并可固定的侧栏。

## 当前结构与交互

- 侧栏依次为首页、生活与记录01、经历与能力02、研究与探索03，`content.paths` 同步三路线顺序，不设分隔组或次级链接。自介并入 `resume` 的展开详情；`about`、`info` 等旧别名与旧链接兼容转到 `resume`，不列入公开命令、补全或帮助。
- 8个公开命令依次为 `home / 0`、`life / 1`、`resume / 2`、`research / 3`、`open`、`close`、`clear`、`help`。`dist/assets/js/commands.js` 是单一命令表，派生解析路由、Tab候选和帮助。视图只保留home、life、resume、research、help；原项目、档案、联系内容与路由、数字4/5及相关别名已删除，旧无效hash回首页，旧命令提示未识别。
- 首页只显示问候标题和“选择左侧目录，或输入 help 查看命令。”，句中的“左侧目录”和 `help` 可点击；不显示身份、兴趣、简介段落或三条命令指南。点击目录提示打开目录并聚焦当前栏目，Escape关闭后回到触发按钮。
- 页面、工具栏、框架和主区采用同一屏幕底色，外框、主区内框与套窗内缩均为零，仅保留工具栏和侧栏内部细分隔线。独立页头、页脚与版权条均不占页面空间。
- 目录具有 `closed`、`pinned`、`peek`、`mobile-open` 四态，每次载入默认收起。桌面左缘悬停、点击或键盘激活均临时覆盖展开，主内容不位移；“目录”旁图钉以 `aria-pressed` 表示固定状态，固定后侧栏占位并跨导航保持，直到取消固定。刷新不记忆固定状态。
- 未固定目录移出后180ms收起，键盘焦点留在目录内时保留，Escape关闭；每次状态切换清理旧计时器。手机通过首页文字提示或44px左侧中部入口打开遮罩抽屉，支持选择、关闭按钮、Escape和遮罩关闭、焦点循环；主动关闭回仍可见的触发按钮，选择路线后聚焦内容。跨760px断点先关闭手机抽屉，返回桌面时沿用本次会话的固定选择。
- 唯一原生输入采用自动吸附：原输入位置不可见时停靠底部，原位置可见时回到正文之后。按 `/`、点击输入或“/ 输入命令”进入命令模式，输入期间固定在底部，执行后可连续输入；Enter 执行，手机使用发送键。镜像块光标保留原生编辑与中文输入，不添加独立执行箭头。
- 命令依次产生 `> command`、短摘要和唯一新提示符，最多五条。栏目摘要使用h2，除标题外的预览在详情展开时隐藏，收起时恢复。详情用原生折叠控件按需展开，首次才创建富文、图片或视频，收起后保留已建内容；关闭详情或后续命令暂停旧视频。
- 默认跟随新输出；向上滚动、触摸/滚动键阅读、拖滚动条、聚焦历史记录或展开详情会暂停。阅读和命令模式中的编辑、Tab补全、↑↓历史回调与 `/` 聚焦保持正文位置；执行新浏览命令才跟随新输出。手动回到底部32px内可恢复跟随。
- 命令模式中 `Esc` 有补全时先关闭候选，再按一次返回正文并保留草稿；“返回阅读”按钮直接退出，手机也可使用。退出后恢复自动吸附，保留Shift+Tab离开路径。输入元素只在初始化时移动一次，滚动和切换位置不移动、不复制输入，不再使用独立“返回输入”按钮。
- 最近记录若有详情，`open` 展开并定位正文，命令模式中仍保留输入焦点；`close` 收起并回输入。`help` 直接显示“浏览路线、操作”两组平面命令按钮与快捷键；命令按钮最小44px高，数字选项独立对齐，使用CSS Grid的8ch命令列，不用制表符。
- 点击侧栏或帮助中的浏览命令会清空会话并选择路线，从正文顶部开始阅读，焦点留在正文；键盘提交命令追加记录并恢复跟随输入。`home`、`clear` 清空回首页。摘要从内容数据生成最多三条标题预览，逐项标记示例；研究与生活的类型数量作为次要信息，介绍留在详情中。经历摘要保留身份、兴趣、履历/PDF状态，详情只渲染一次完整个人介绍，不重复栏目标题或身份、兴趣标签块。
- 详情条目用h3、经历条目用h4；示例标识放在条目标题旁，不再重复全局示例说明。详情与媒体左对齐且最大960px，段落最大72ch；图片可在新标签页打开原图。页面框架保持满视口，760px以下目录关闭时主区左内边距44px、右20px，480px及以下摘要标签和值上下排列。
- Tab 在输入中补全，非 Shift 的 Tab 始终保持输入焦点：唯一匹配补全、多匹配循环列表候选、空输入也可使用、无匹配不跳焦。Shift+Tab 可离开，↑↓ 回调历史。输入行右侧始终显示“/ 输入命令”或“Esc 返回阅读”。组合输入、其他编辑区、文字选择、媒体与目录上下文不触发快捷唤起。错字建议比较完整拼写，例如 `reserch` 提示 `research`。
- 宽屏工具栏“就绪 / 输入中”直接同步真实输入，没有假加载延迟；1000px 以下隐藏状态。左缘目录入口和图钉使用图标与动态无障碍名称，首页文字入口使用明确标签；短动画、减少动态效果及隐藏标签页暂停规则保持不变。
- 默认琥珀，另有荧绿；工具栏右侧为一个两档开关，checked 表示荧绿。760px 以下隐藏路径和当前主题文字以保持单排，开关语义仍完整。URL与偏好优先级保留，只有手动切换开关保存；`theme` 从帮助和补全移除，输入旧命令会提示使用右上角开关。
- 命令输入、回显、路径与快捷键使用本地 IBM Plex Mono Regular 400 / Medium 500；中文说明、摘要与详情沿用既有衬线字体。IBM字体来自官方仓库，随附 SIL OFL 1.1 许可。

## 唯一输入体验

自动吸附与命令模式已选定为唯一默认体验，由 `dist/assets/js/command-input.js` 与 `dist/assets/css/command-input.css` 提供。版本切换栏、对比页和其他输入分支已移除。旧链接中的 `input` 参数清除后进入同一最终版本，保留主题参数与栏目位置。

初始保持阅读状态，不自动聚焦输入。首页显示问候和入口；初次直接打开有详情的栏目链接时展开详情，侧栏导航仍先显示短摘要。只保存用户手动选择的主题，不持久保存命令模式或草稿。
