# LizPink 个人终端

这是 LizPink 个人终端的当前版本，采用自动吸附与命令模式。页面铺满视口并与背景融为一体，取消外框、套窗内缩和居中限宽；标志、姓名与主题仍在紧凑工具栏，图钉位于侧栏“目录”旁。目录每次载入默认收起，终端独立滚动，最多保留五次输出；原输入位置不可见时，命令行自动吸附到底部。

首页只保留问候标题与“选择左侧目录，或输入 help 查看命令。”；句中的“左侧目录”和 `help` 均可点击。目录提示会打开目录并聚焦当前栏目，Escape 关闭后回到触发入口。侧栏依次为首页、生活与记录01、经历与能力02、研究与探索03。经历摘要展示身份、兴趣与简历状态，展开后直接阅读完整介绍和图文，避免重复身份与兴趣标签。原项目、档案与联系内容及入口已删除；`about`、`info` 等旧别名和旧链接会转到经历。示例均就近标识，日后可替换或留空，不表示个人经历或成果。

桌面悬停、点击或键盘激活左缘，会临时覆盖展开目录；未固定时移出180ms后收起，键盘焦点留在目录内时保留，Escape可关闭。点击目录旁图钉固定，再次点击取消；`aria-pressed` 同步固定状态。固定跨导航保持，刷新后恢复收起。760px 以下为左侧抽屉，点击左侧中部入口打开，选择、关闭按钮、Escape或遮罩可关闭，Tab在抽屉内循环。切至手机时关闭抽屉，返回桌面时沿用本次会话的固定选择。

## 从设计到上线的六步流程

| 步骤 | 要做的事 | 本次结果 |
| --- | --- | --- |
| 1. 明确用途 | 确定展示对象与访客要找到的信息 | 围绕生活与记录、经历与能力、研究与探索三路线组织内容 |
| 2. 盘点内容 | 核对旧内容、链接和真实资料 | 当前保留三路线的示例文字、图片、视频与待补简历 |
| 3. 确定结构 | 先确定页面入口，再画界面 | 满视口统一背景、四项侧栏及左缘展开；自介并入经历，保留有限会话与手机抽屉 |
| 4. 做可操作草稿 | 比较视觉方向，验证交互 | 琥珀与荧绿终端，默认琥珀；支持点击、指令与数字选项 |
| 5. 检查体验 | 检查手机、键盘、链接、媒体和错误输入 | 重点核对可点击入口、详情收展、窄屏阅读、帮助按钮和错字建议；历史记录见 verification.json；未提供的 PDF 不显示下载入口 |
| 6. 上线与维护 | 发布选定版本，保留恢复方式 | 2026-10-25 已将当前版本发布至 [lizpink.github.io](https://lizpink.github.io/)；旧版已保存备份分支，旧 Hugo 发布流程已移除 |

页面使用纯 HTML、CSS、JavaScript，不需要 Hugo、数据库或依赖安装。此前入口与阅读优化已通过1661px桌面、390×844与320×640手机视口检查：目录焦点、帮助点击、单一标题、阅读宽度及错字建议正常，无横向溢出，浏览器error/warn为0。详细范围见DESIGN.md的Verification。

## 自动吸附与命令模式

打开网站默认地址即可使用最终体验。阅读时，命令行在原位置不可见时吸附到底部，滚到原位置后回到正文之后。网站只保留这一套输入方式，版本切换栏和对比页已移除；旧链接中的 `input` 参数会被清除，主题参数与栏目位置保留。

按 `/`、点击输入区或“/ 输入命令”进入命令模式，输入期间固定在底部，执行后可继续输入。`Esc` 先关闭补全候选，再退出到正文并保留草稿；也可点击“返回阅读”。首页不自动聚焦输入；初次直接打开有详情的栏目链接时会展开详情，侧栏导航仍先显示短摘要。

可以滚到正文中段，按 `/` 输入一段草稿，再按 `Esc` 返回阅读；继续滚动后按 `/`，继续编辑同一份草稿。使用 Tab 补全后，第一次 Esc 收起候选，第二次返回阅读。

| 公开命令、内部兼容别名与帮助 | `dist/commands.js`；解析路由、Tab候选、可点击帮助与错字建议共用命令表 |

| 默认颜色与记住选择规则 | `dist/theme.js` 的 `DEFAULT_THEME`（当前为 `amber`）；`dist/index.html` 的 `data-theme` 与主题色元数据保留相同默认值 |
| 颜色、字号、间距 | `dist/styles.css` |
| 字体、许可与回退 | `dist/fonts/` 及 `styles.css` 的 `@font-face`、`--font-body`、`--font-mono` |

PDF 链接只有填入有效路径后才显示。访客点击后在新标签页打开 PDF，可以使用浏览器自带的下载按钮。上传文件需要你更新本地文件再重新发布，网站内没有管理后台。

三条路线通过 `paths` 的 `items` 引用同一份 `samples`，例如 `geometry` 同时出现在经历与研究中；改一次会在两处同步显示。

### 替换文字、图片和视频

在 `dist/content.js` 中找到对应的 `samples` 条目，保留其键名（如 `geometry`），按以下方式修改：

| 想修改什么 | 具体操作 |
| --- | --- |
| 文字 | 改 `title` 和 `text`；纯文字条目使用 `type: "text"` |
| 图片 | 将真实图片放入 `dist/media/`；保留 `type: "image"`，把 `src` 改成 `"./media/你的图片文件名"`，并更新 `alt`（图片内容说明）与 `caption`（图下说明） |
| 视频 | 将真实视频放入 `dist/media/`；保留 `type: "video"`，更新 `src`、`title`、`text` 与 `caption`；`poster` 填对应封面路径，不需要封面可设为 `""` |
| 视频字幕 | 将与真实视频对应的中文 `.vtt` 文件放入 `dist/media/`，更新 `captions`；没有对应字幕时设为 `""` 或删除此字段，不要沿用旧示例动画的说明 |
| 从示例改成真实内容 | 替换相应文字、真实媒体、替代文字、封面、图注和字幕后，将该条的 `example: true` 改为 `example: false` |
| 保留示例 | 保持 `example: true` 及路线中的引用，页面继续显示示例标识 |
| 隐藏一条内容 | 从相应 `paths` 条目的 `items` 中移除键名；若被两条路线引用，需分别移除。可继续保留 `samples` 内的内容供日后使用 |
| 某条路线完全留空 | 将这条路线的 `items` 改为 `[]`；标题、介绍与待整理提示仍保留，条目与媒体不显示 |

`example: false` 只控制网页外部徽标，不能清除示例图片或视频画面内的 DEMO 字样；成为真实内容时需换成真实文件。简历的 `sections: []` 与 `pdfUrl: ""` 可继续留空，日后再补。

目前示例文件：`demo-geometry.svg`（960×540）、`demo-notebook.svg`、`demo-orbit.mp4`（6秒、640×360、24fps、H.264/yuv420p、无声）、`demo-orbit-poster.svg`、`demo-orbit.zh.vtt`。视频使用浏览器原生控制、`preload="none"`，不自动播放。查看视频和字幕时建议使用下面的本地预览地址。

改动后保存，刷新预览，先核对各路线短摘要，再展开详情检查图片、视频、图注与字幕，并试一次命令。无需为了更新一句话而修改页面布局。

## 本地查看

直接双击 `dist/index.html` 即可使用（偏好保存是否可用取决于浏览器）。也可以从项目目录运行：

```text
python -m http.server 4173 --bind 127.0.0.1 --directory dist
```

打开 <http://127.0.0.1:4173/?theme=amber> 或 <http://127.0.0.1:4173/?theme=green>。工具栏右侧为两档主题开关，checked 表示荧绿；760px 以下隐藏当前主题文字与路径，开关语义保持完整。目录旁的图标按钮和左缘入口可用键盘操作，均有无障碍名称。

首次打开按“有效的 `?theme=` 参数 → 有效的已保存选择 → 琥珀”决定配色。只有手动切换右上角开关才记住选择；打开带配色参数的链接本身不会覆盖已保存偏好。`theme` 已移出公开命令、帮助和补全，输入旧命令会提示使用开关。无参数、无有效保存值时使用琥珀。无效参数或无效保存值会被忽略，无法保存偏好时仍可正常切换。

手动切换时，若地址已含 `theme` 参数，会同步为新选择，并保留其他参数与当前页面的 hash；普通地址不会额外添加主题参数。`theme.js` 在样式表之前执行，先应用主题，再显示页面，避免已选荧绿的访客先看到琥珀。

侧栏提供四个主入口。8个公开命令依次为 `home / 0`、`life / 1`（生活与记录）、`resume / 2`（经历与能力）、`research / 3`（研究与探索）、`open`、`close`、`clear`、`help`。视图只保留home、life、resume、research、help；原项目、档案与联系路由、数字4/5及相关别名已删除。无效hash返回首页，旧命令提示未识别，不迁入life。

输入或点击 `help` 直接显示“浏览路线、操作”两组平面命令列表与快捷键，无需展开；每个命令都是最小44px高的可点击按钮。“或N”使用CSS Grid独立对齐，命令列固定8ch，不使用制表符。原生输入无底线、无独立执行箭头；按Enter执行，手机键盘使用发送键。输入行右侧显示“/ 输入命令”或“Esc 返回阅读”。镜像块光标不替代真实编辑和中文输入。普通 Tab 始终保持输入焦点：唯一匹配补全，多匹配循环候选；空输入可用，无匹配不跳焦。Shift+Tab 可离开，↑↓ 回调历史；`/` 唤起命令模式并保留阅读位置，Escape 先关闭补全，再返回阅读并保留草稿。菜单打开时，Escape 仍负责关闭未固定目录或手机抽屉。组合输入、其他编辑区、选中文字、媒体与目录上下文不会触发快捷唤起。未识别命令按完整拼写距离建议候选，例如 `reserch` 提示 `research`。

键盘提交命令留下真实回显和短摘要，最多保留五条；唯一新输入自动跟随可见。点击目录或帮助中的浏览命令会清空会话并从正文顶部阅读，焦点留在正文。摘要使用栏目标题和最多三条内容标题预览，示例逐项标注；研究与生活的类型数量放在次要信息中。经历摘要另保留身份、兴趣与待补履历/PDF状态，完整介绍只在详情出现。

点击“展开…”、输入 `open`，或首次直接访问有详情的栏目链接时，才创建对应记录的完整图文。展开时隐藏摘要预览、保留单一栏目标题，正文不再重复栏目标题、身份和兴趣标签；示例标识放在条目标题旁。命令模式中执行 `open` 后仍保持输入焦点，方便连续输入。输入 `close` 收起并回输入，摘要预览恢复；已创建的内容保留，视频暂停。

详情和媒体左对齐、最大960px，段落最大72ch；页面框架仍铺满视口。点击图片可在新标签页查看原图。760px以下主区左右内边距为20px，目录关闭时左侧为44px；480px及以下的摘要标签和值上下排列，为长兴趣名称留出宽度。

向上滚动、触摸/滚动键阅读、拖滚动条、聚焦历史记录或展开详情，会暂停自动跟随；阅读时不强拉到底。命令行自动吸附保证输入入口可见，命令模式中编辑、Tab 补全和↑↓回调历史保持正文位置；执行新浏览命令才跟随新输出。退出命令模式后恢复原位可见性判断，不再使用独立“返回输入”按钮。侧栏清会话，`home`、`clear` 回首页，宽屏状态继续即时同步真实输入。

屏幕显像340ms、输出显现150ms、块光标950ms闪烁、手机抽屉200ms、主题滑块180ms。系统减少动态效果设置关闭动画与位移；标签页隐藏时暂停光标闪烁。

## 字体与许可

标题、中文说明、摘要与界面使用本地 **Source Serif 4** 及中文衬线回退；命令输入、回显、路径和快捷键使用本地 **IBM Plex Mono**。原 `lp_` 标志保留既有等宽栈。

本地文件为 `dist/fonts/SourceSerif4Variable-Roman.ttf.woff2`（429,100字节），来自 Adobe 官方 Source Serif 发行文件的 `WOFF2/VAR` 目录，采用 SIL Open Font License 1.1；许可保存在 `dist/fonts/LICENSE.md`，随字体一同保留。CSS 声明常规体可变字重 200–900，使用 `font-display: swap` 与自动光学字号；页面预加载该字体，不依赖在线字体服务。

IBM Plex Mono 来自 [IBM 官方 Plex 仓库](https://github.com/IBM/plex)，本地文件为 `dist/fonts/IBMPlexMono-Regular.woff2`（400）与 `dist/fonts/IBMPlexMono-Medium.woff2`（500）。两者使用 `font-display: swap`，预加载Regular；SIL Open Font License 1.1 许可保存在 `dist/fonts/IBM-Plex-Mono-LICENSE.txt`。等宽回退为 `Cascadia Mono → Consolas → Microsoft YaHei → monospace`。

中文未另行打包字体，按 `Noto Serif SC → Source Han Serif SC → Songti SC → SimSun → serif` 回退，具体外观取决于设备已安装字体。字体文件不可用时也沿同一栈回退。若替换字体，应同步更新 `@font-face`、首页预加载路径、字体栈与相应许可。

## 文件分工

`index.html` 是页面结构，`styles.css` 是基础外观，`command-input.js/css` 负责自动吸附、命令模式和输入区布局，`theme.js` 负责首次配色及保存，`commands.js` 维护公开命令、内部别名、帮助、补全与错字候选，`summaries.js` 生成短摘要与展开标签，`app.js` 负责目录、指令、按需详情和跟随/阅读状态；`content.js` 是个人资料与三路线内容。`.openai/hosting.json` 声明当前 Sites 托管配置。

`PRODUCT.md` 记录用户图示优先、满视口、四态目录与有限会话等当前约束；`DESIGN.md` 记录当前布局、主题开关、输入、补全与动画，`.impeccable/design.json` 保留既有提取快照。当前身份与兴趣来自用户确认；本轮未添加真实内容或PDF，示例不作为个人履历或成果。当前公开版本已在 GitHub Pages 上线，部署与备份记录见上节及 `github-pages-deployment.json`。
